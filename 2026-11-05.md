# 5 Nov 2026: Reporting reviews, a review login, and a real account deletion

**Short version:** shoppers can now report a review from the app and staff remove it from the admin panel; App Store / Play reviewers get a phone number with a fixed code that works on production; and deleting an account now deletes the shopper's personal details too.

**Who has to act:** the customer app team (point the Report sheet at the new endpoint), and whoever runs Dokploy (two env vars, one migration).

---

## Report a review

```
POST /api/customer/reviews/{id}/report
{ "reason": "spam", "details": "Advertising another shop." }
```

`reason` must be one of: `spam`, `offensive`, `fake`, `off_topic`, `personal_info`, `other`. `details` is optional (up to 1000 characters).

| Answer | Means |
|---|---|
| `201` | Reported. |
| `200` | Already reported by this shopper; the reason was updated. |
| `404` | The review is hidden or does not exist. |
| `422` on `review` | It is the shopper's own review. |

Response (`201` / `200`):

```json
{
  "reported": true,
  "message": "Thanks — our team will take a look at this review.",
  "data": {
    "id": 12,
    "review_id": 345,
    "reason": "spam",
    "details": "Advertising another shop.",
    "status": "open",
    "created_at": "2026-11-05T10:15:00+05:30"
  }
}
```

Show `message` as the toast. Needs the shopper's Bearer token; limited to 20 reports a minute.

The review stays up until someone at the marketplace decides.

## For the admin

**Admin → Catalog → Reviews** (needs the Products permission). The sidebar badge counts reviews waiting on a decision.

- **Remove review** — hides it from everyone except its author and takes it out of the star average. Every open report on it is marked resolved.
- **Keep it up** — dismisses the reports; the review stays.
- **Restore** (on the Removed tab) — puts a removed review back.

## App-review login

| Phone | OTP |
|---|---|
| `9876543210` | `111173` |

This number signs in with this code through the normal OTP screens (`POST /auth/otp` → `POST /auth/otp/verify`), on production. No SMS is sent. **Nothing changes in the app** — just make sure the phone field accepts this number.

Put the same number and code in App Store Connect → App Review Information, and in Play Console → App access.

(Server side: `DEMO_LOGIN_PHONE=9876543210` and `DEMO_LOGIN_CODE=111173` in Dokploy's env editor. Remove either and the demo login switches off.)

## Account deletion

`DELETE /api/customer/me` now also erases the name, date of birth, gender, photo, password, saved addresses, saved payment methods, wishlist, basket and the shopper's reviews. Orders, invoices, refunds, store credit and support tickets are kept, as before. The `/account/delete` page says the same.

## Deploying

This ships a migration (`review_reports` table). Run `php artisan migrate --force` against the live database after deploying.
